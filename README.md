# Projeto_-Agrinho

este projeto foi desenvolvido para o Agrinho 2026 com o tema **"Tecnologia Na Agricultura"**.
---
O site é um catálago que mostra as alteraçóes causadas pela implementação de tecnologia no meio da agricultura.
---
Tecnologias:
- HTML;
- CSS;
- Javascript;
- Alguns conteúdos e elementos aplicados ao site foram criados com auxilio de ferramentas de IA.
